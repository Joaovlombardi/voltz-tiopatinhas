# Projeto PBL Voltz - Missão Tio Patinhas (Fase 2)

Este projeto foi desenvolvido para a Fase 2 do PBL, com foco na implementação das classes em Java utilizando conceitos de orientação a objetos.

## Objetivo

Modelar um sistema de controle de investimentos em criptomoedas por meio de classes Java.

## Estrutura do Projeto

O projeto está organizado em:

- model: classes principais do sistema
- service: serviço de cotação (simulação)
- Main: classe de execução para testes

## Classes Desenvolvidas

- Usuario
- Carteira
- Criptomoeda
- Ativo
- Transacao
- Aporte
- Cotacao
- ApiCotacaoService
